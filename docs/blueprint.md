# **App Name**: AuthFlow Dashboard

## Core Features:

- Authentication: Implement user authentication using Clerk for secure sign-in and sign-out functionality.
- Dashboard Access: Restrict access to the dashboard pages only to authenticated users.
- User Profile: Display basic user profile information on the dashboard after login.
- Protected Routes: Implement middleware to protect specific routes, ensuring that only authenticated users can access them.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to establish trust and security.
- Background color: Light gray (#F5F5F5), a very low saturation version of the primary hue to avoid distracting users from the main dashboard content.
- Accent color: A vibrant orange (#FF5722) to create clear visual contrast in interactive elements, for example on the Sign In and Sign Out buttons.
- Font: 'Inter', a grotesque-style sans-serif with a neutral, modern look, appropriate for body and headline text.
- Use a consistent set of icons from a library like FontAwesome or Material Icons to represent different actions and data types within the dashboard.
- Design a clean and responsive layout for the dashboard, ensuring it is accessible on different screen sizes. Use a grid-based system for content alignment.
- Add subtle transitions and animations for a smoother user experience when navigating between routes and interacting with dashboard components.
